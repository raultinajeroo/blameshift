# Impact

What is actually known about this project's usage and effect. Written
deliberately conservative: if a number is not listed here, we do not have
it.

## Metrics that ARE collected

- **CI status.** Test pass/fail on GitHub Actions, visible on the commit
  history and PR checks. That is the only automated signal.
- **Repository traffic.** GitHub's built-in traffic view (clones, views)
  is available to the owner, but is not tracked, archived, or published.

## What is NOT collected or known

- **No usage telemetry.** The tool runs fully offline, phones home to
  nothing, and reports nothing. There is no way to know how many times it
  has been run, by whom, or on what data.
- **No adoption numbers.** No known users, teams, or organizations running
  this in production. Any such claim would be fabrication.
- **No uptime or production claims.** This is a command-line research tool,
  not a service; there is nothing to keep up.
- **No measured real-world outcomes.** All numbers in the README, reports,
  and CLI output come from synthetic, fixture-derived demo data generated by
  `blameshift simulate` or committed under `examples/demo/`. They
  demonstrate that the detection and attribution logic works on a planted
  shift; they say nothing about performance on anyone's real series.

## How impact would be evidenced

If this ever changes (e.g. someone reports using it), evidence would be a
link to a public issue, discussion, or write-up — not a self-reported
number.
