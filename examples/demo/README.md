# Demo (offline, fixture-derived)

This directory holds a **bundled synthetic demo**: every number in these
files is fixture-derived, generated by `blameshift simulate` with a fixed
seed. Nothing here is real production data.

- `series.csv` — 400 synthetic latency samples with one planted +15%
  regression at sample 240 (2026-01-05 20:00 UTC).
- `changes.json` — synthetic change log; `deploy-482` is the planted cause,
  `deploy-479` is an in-window decoy.
- `truth.json` — the answer key for the planted shift.
- `report.json` / `report.html` / `run_output.txt` — the outputs of the run
  below, committed so you can see expected results without running anything.

## Run it

No network, API keys, or services needed:

```bash
pip install -e .

# Regenerate the fixtures (overwrites series.csv, changes.json, truth.json):
blameshift simulate --out examples/demo --points 400 --seed 7

# Detect the shift and attribute blame:
blameshift run --series examples/demo/series.csv \
               --changes examples/demo/changes.json \
               --json report.json --html report.html
```

Expected: 1 change point detected at 2026-01-05 20:00 UTC, attributed to
`deploy-482` (score 0.75), matching `run_output.txt`.
